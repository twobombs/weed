# Examples

This directory contains example code demonstrating how to use the Weed library for various machine learning tasks. Each example showcases different aspects of the library, from basic tensor operations to complete neural network training.

## Files

### [`xor.cpp`](xor.cpp)
A simple example that trains a neural network to learn the logical XOR function.

**Purpose:**
- Demonstrates basic tensor creation
- Shows how to build a simple neural network
- Illustrates the training loop with autograd
- Shows model saving and loading
