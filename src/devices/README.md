# Weed Devices Source Code

This directory contains device-specific implementations for the Weed library, primarily focused on GPU acceleration using OpenCL.

## Overview

The `src/devices/` directory implements device management and GPU-specific functionality. It provides the bridge between the high-level tensor operations and the underlying hardware.
